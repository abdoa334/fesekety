# fesekety
تطبيق "فى سكّتى" لتوصيل الطلبات عبر المسافرين. يربط بن العميل الذى يرغب فى توصيل طلبية بالمسافر الذى يتنقل داخل او خارج المدن. يقوم المسافر بانشاء حساب فى نسخة المسافر fesekety traveler ثم ينتظر توثيف الحساب.بعد ذلك ينشئ رحلة يحدد فيها موعد الانطلاق و الحمولة و وصف المسار على الخريطة بالنقاط ووسائل التنقل المستخدمة.والعميل يسجل حساب فى نسخة fesekety وينشئ طلب يحدد حجم الطلب وموعد الاستلام ومكان البداية والوجهة. المسافر و العميل من خلال كل نسخة يتوجهان الى مكان البداية ويتمان عملية الاستلام. ثم يتوجه المسافر الى الوجهة ويلتقى بالمستلم الذى يأخذ كود التحقق من العميل ويعطيه للمسافر ليتحقق وبعد ذلك يسلم الطلبية.
